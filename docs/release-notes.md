# Release Notes — v1.0.0

## Implemented

- Log Complaint Tool
- Edit Complaint Tool
- Document Extraction for PDF, DOCX, TXT, and EML
- Preliminary AI Risk Assessment
- Completeness, duplicate detection, summary, investigation, and CAPA insights
- PostgreSQL persistence with Alembic migrations
- Append-only audit trail and complaint history
- Read-only complaint form with AI-only mutation paths

## Known limitations

- Not a validated production GxP system.
- No production OCR for scanned PDFs.
- No authentication or RBAC.
- No electronic signatures.
- AI recommendations require QA review.

Release tag preparation target: `v1.0.0`. No tag is created or pushed by this
phase.
