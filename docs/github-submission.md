# GitHub Submission Guidance

## Suggested repository description

> AI-powered pharmaceutical customer complaint management system using React,
> Redux, FastAPI, LangGraph, Groq and PostgreSQL. Supports natural-language
> complaint logging/editing, document extraction, risk assessment and audit
> history.

## Suggested topics

`ai` `langgraph` `fastapi` `react` `redux` `postgresql` `groq`
`pharmaceutical` `qms` `llm`

## Repository presentation order

1. Start with the one-paragraph summary and Core Capabilities in `README.md`.
2. Link the working demo video and technical walkthrough from the final
   submission document.
3. Keep the exact demo prompts and recording scripts in `docs/recording/`.
4. Keep sample files in `sample_documents/` and identify them as fictional.
5. Show the requirement mapping and release notes during final review.

Do not change GitHub metadata, push commits, create tags, or modify a remote
repository as part of this local preparation phase.
