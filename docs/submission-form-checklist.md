# Final Submission Form Checklist

Complete this checklist immediately before submitting the assignment.

- [ ] Copy the final GitHub repository URL from the intended repository.
- [ ] Copy the working demo video URL for
  `pharma-complaint-working-demo.mp4`.
- [ ] Copy the technical walkthrough video URL for
  `pharma-complaint-code-walkthrough.mp4`.
- [ ] Add a live application URL if one is deployed.
- [ ] Replace every placeholder in `docs/final-submission.md`.
- [ ] Confirm the submitted repository is the final project and contains the
  expected README and supporting documentation.
- [ ] Confirm the repository is accessible to evaluators.
- [ ] Confirm both video links open without a sign-in or request-access wall.
- [ ] Verify the video permissions in an incognito/private browser window.
- [ ] Confirm the working demo video has the Log, Edit, Document, Risk, save,
  history, and audit demonstrations.
- [ ] Confirm the code walkthrough covers the required architecture and tools.
- [ ] Confirm no secrets, private credentials, or unintended local artifacts
  are included in the repository.
- [ ] Review the final form once after pasting every URL, then submit.
