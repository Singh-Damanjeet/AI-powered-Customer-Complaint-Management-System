# Screens to Capture

Capture real application screenshots only. Do not generate fake screenshots or
include secrets, API keys, database URLs, or personal data.

1. **Empty complaint UI** — read-only badge, empty fields, Copilot, disabled
   Save button, and empty history.
2. **AI-populated complaint** — ABC Pharma, Metformin Hydrochloride, 500 mg,
   batch, dates, quantity, and discoloration details.
3. **Risk assessment** — severity, priority, rationale, QA investigation flag,
   and recommended actions with the QA disclaimer visible.
4. **Edit highlighting** — batch and quantity changed while unrelated values
   remain visible and unchanged.
5. **Document upload result** — selected PDF, extracted complaint, and risk
   result.
6. **Completeness checker** — score, status, message, and missing fields when
   applicable.
7. **Duplicate warning** — `Possible Duplicate`, similarity score, matching
   fields, and review-oriented reason.
8. **CAPA/investigation suggestions** — potential investigation areas and the
   `AI recommendation — QA review required` disclaimer.
9. **Audit trail** — creation, field changes, risk reassessments, document
   extraction, source, old/new values, and timestamps.
10. **Saved complaint number** — saved state, complaint number, persisted
    history, and disabled post-save controls.

## Capture hygiene

- Use a consistent browser viewport and zoom for all screenshots.
- Capture the full relevant card without clipping long content.
- Use the fictional sample data only.
- Check that the browser has no horizontal overflow before capture.
- Keep the screenshot set small and label each image with the sequence number.
